# WooCommerce Plugin Compatibility Matrix

| Extension / Category | Plugin Type | Compatibility | Notes |
| :--- | :--- | :--- | :--- |
| **WooCommerce Core** | E-Commerce Engine | **Required (100%)** | Powers catalog, taxes, stock, cart, and checkout. |
| **Cash on Delivery (COD)** | Payment Gateway | **Native (100%)** | Built-in WooCommerce COD gateway auto-detected. |
| **Razorpay / Stripe** | Payment Gateway | **Supported** | Gateways active in WooCommerce appear dynamically in checkout. |
| **WooCommerce Coupons** | Discounts | **Native (100%)** | Fully supported via Store API coupon endpoints. |
| **Standard Shipping Rates** | Shipping | **Native (100%)** | Auto-calculated by WooCommerce Store API in cart/checkout. |
| **Custom Food Modifiers** | Customization | **Native (100%)** | Spice level, portion, and curry addons handled via Foodgo Headless Connector. |
