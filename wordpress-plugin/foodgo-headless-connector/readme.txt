Decoupled Headless WooCommerce & WordPress integration plugin for the Foodgo React Frontend.

== Description ==
Foodgo Headless Connector bridges your WooCommerce store with the Foodgo React frontend. It provides dynamic frontend auto-discovery, Store API cart extensions, and support for food customization.
